The guard skips a `#` comment until a line-feed character, but PowerShell also treats a carriage return as a line ending. For example, a command containing `# comment\rcodex exec -m gpt-6.1-terra -` is treated by the guard as one comment, while PowerShell executes the command after `\r`. This allows an unapproved model invocation to pass the model guard. **Confidence: high; evidence source: committed code and read-only reproduction.** Stop comment scanning at either `\r` or `\n`, and add a regression case for a carriage-return-only line ending.
